# Python Assignment 2 – Data Structures and Conditional Statements

## 📌 Project Overview

This repository contains Python exercises completed as part of my Python learning journey. The assignment focuses on understanding and implementing fundamental Python data structures and conditional statements.

The objective is to develop a strong foundation in Python by performing operations on lists, dictionaries, and sets, along with implementing decision-making logic using conditional statements.

## 🎯 Topics Covered

- Lists – Creation, modification, sorting, and accessing elements.
- Dictionaries – Creating, accessing, adding, and updating key-value pairs.
- Sets – Understanding unique elements, set operations, and set limitations.
- Conditional Statements – Implementing decision-making using `if`, `elif`, and `else`.
- Logical Operators – Using `or` to validate user input.

## 📝 Assignment Tasks

### 1. Lists

Performed various list operations using Python:

- Created lists containing integer and string elements.
- Used `append()` to add elements.
- Used `insert()` to add elements at specific positions.
- Used `remove()` and `pop()` to delete elements.
- Used `extend()` to add multiple elements.
- Sorted lists in descending order using `sort()`.
- Calculated maximum, minimum, and sum using `max()`, `min()`, and `sum()`.
- Accessed elements using positive and negative indexing.
- Extracted elements using list slicing.
- Reversed lists using slicing.

### 2. Dictionaries

Created and manipulated a dictionary containing student names and their marks.

Operations performed:

- Created a dictionary using key-value pairs.
- Accessed values using dictionary keys.
- Added new student records.
- Updated existing student marks.
- Retrieved dictionary keys using `keys()`.
- Retrieved dictionary values using `values()`.
- Retrieved key-value pairs using `items()`.

### 3. Sets

Explored Python sets and their operations.

Tasks performed:

- Created a set containing vowel elements.
- Observed how sets automatically eliminate duplicate values.
- Explored why sets do not support indexing or item assignment.
- Created two sets containing integer elements.
- Performed union and intersection operations.

Methods and operators used:

- `add()`
- `remove()`
- `discard()`
- `union()` / `|`
- `intersection()` / `&`

### 4. Conditional Statements

Developed a Performance Category Program using `if`, `elif`, and `else`.

The program accepts a score between 0 and 10 and categorizes performance based on the following conditions:

| Score | Performance Category |
|---|---|
| Greater than 7 | Above Average |
| 4 to 7 (inclusive) | Average |
| Less than 4 | Below Average |

The program also validates user input and displays appropriate messages for each performance category.
