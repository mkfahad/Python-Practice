## 📝 Assignment Questions

### 1. Number Guessing Game – While Loop

**Problem Statement:**

Develop a number guessing game where the computer generates a random number between 1 and 10, and the user gets three attempts to guess the correct number.

**Key Implementations:**
- Generate a random number using `random.randint()`.
- Use a `while` loop to manage the guessing attempts.
- Provide feedback if the guess is too high or too low.
- Use `continue` to handle invalid guesses.
- Use `break` when the correct number is guessed.
- Use the `while-else` statement to display a message when all attempts are exhausted.

### 2. Multiplication Table Generator – For Loop

**Problem Statement:**

Create a Python program that generates a multiplication table (1 to 10) for a number entered by the user.

**Key Implementations:**
- Accept a number from the user.
- Use a `for` loop with the `range()` function.
- Calculate the multiplication result in each iteration.
- Display the multiplication table in a structured format.

### 3. BMI Calculator – Functions

**Problem Statement:**

Develop a Python program to calculate Body Mass Index (BMI) using a user-defined function.

**Formula:**

BMI = Weight (kg) / Height (m)²

**Key Implementations:**
- Define a function `calculate_bmi(weight, height)`.
- Accept weight and height as user inputs.
- Pass the input values as function arguments.
- Calculate BMI inside the function.
- Return the calculated BMI using the `return` statement.
- Display the result using formatted output.
